# 🚀 TH Tools — Multi-Service Digital Portal & Order Management System

**TH Tools** is a complete, production-ready multi-service web platform built with **PHP** and **MySQL**. Designed for digital service providers and agencies, it centralizes automated & manual service processing, user wallet management, deposit tracking, and order fulfillment into a sleek, mobile-friendly dashboard.

🔗 **Live Demo:** [https://tools.totthohub.com](https://tools.totthohub.com)

## ✨ Key Features

### 👤 User Panel
* **Modern Responsive Dashboard:** Clean, fast, and mobile-first UI for seamless access across devices.
* **Service Modules:** Dedicated interfaces for Document Lookup, Server Copy, Official Copy, Identity Verification, and Built-in Script Shop.
* **Wallet & Recharge System:** Instant account balance tracking, deposit requests, and complete transaction history.
* **Real-Time Order Tracking:** Track pending, processing, and completed service requests.

### 🛡️ Advanced Admin Panel
* **Comprehensive Analytics:** Overview of total users, revenue, deposits, and daily order volume.
* **Dual Processing Modes:** Supports both **Automated API Processing** and **Manual Order Fulfillment**.
* **Dynamic Pricing & Service Control:** Add, edit, enable/disable services and set custom pricing anytime.
* **User & Deposit Management:** Approve/reject deposit requests and adjust user balances.
