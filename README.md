# 🚀 TotthoHub Tools — Multi-Service Digital Portal & Order Management System

**TotthoHub Tools** is a comprehensive, production-ready multi-service web platform built with **PHP** and **MySQL**. Designed for digital service providers, agencies, and entrepreneurs, it centralizes NID verification services, voter search lookups, automated/manual order processing, user wallet management, deposit tracking, and order fulfillment into a sleek, mobile-friendly dashboard.

🔗 **Live Demo:** [https://tools.totthohub.com](https://tools.totthohub.com)

## ✨ Key Features

### 👤 User Panel
* **Modern Responsive Dashboard:** Clean, fast, and mobile-first UI for seamless access across devices.
* **NID & Voter Lookup Modules:** Dedicated interfaces for NID Verification, Voter Information Search, and document processing.
* **Wallet & Recharge System:** Instant account balance tracking, deposit requests, and complete transaction history.
* **Real-Time Order Tracking:** Track pending, processing, and completed service requests.

### 🛡️ Advanced Admin Panel
* **Comprehensive Analytics:** Overview of total users, revenue, deposits, and daily order volume.
* **Dual Processing Modes:** Supports both **Automated API Processing** and **Manual Order Fulfillment**.
* **Dynamic Pricing & Service Control:** Add, edit, enable/disable services (including NID & verification tiers) and set custom pricing anytime.
* **User & Deposit Management:** Approve/reject deposit requests and adjust user balances.

## 🛠️ Technology Stack

* **Backend:** PHP 8.x
* **Database:** MySQL 5.7 / 8.0
* **Frontend:** HTML5, CSS3, Responsive JavaScript

---

## ⚙️ Server Requirements

* PHP `7.4` or `8.x`
* MySQL `5.7+` or MariaDB `10.x+`
* Apache / Nginx Web Server
* Standard PHP Extensions (`mysqli`, `pdo`, `curl`, `json`, `mbstring`)

---

## 🚀 Quick Installation Overview

1. Extract the source code package to your server's `public_html` or subdomain directory.
2. Create a new **MySQL Database** and user, then import the provided `.sql` file.
3. Update the database credentials in the configuration file.
4. Log in to the **Admin Panel** using the default credentials provided in the documentation and configure your services.
